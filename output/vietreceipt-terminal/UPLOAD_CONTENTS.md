# What's included

- `run_receipt.py`, `stages.py`: terminal orchestration and component adapters.
- `bundles/HEADER-CHECKPOINT-TICH-HOP/`: current Header OCR adapter and its VietOCR checkpoint.
- `bundles/retail/`: structured line-item extraction and tests.
- `bundles/footer/`: PaddleOCR Footer reader.
- `samples/header/`: the included Header sample images.
- `git-20/`: the 20-image evaluation set, gold references, and source manifest.
- `../../output/pp-doclayout-v3-1511/`: PP-DocLayoutV3 adapter code and model checkpoint.
- `../../reports/table-footer-20-20261116/`: browser report, terminal log, JSON scores, and screenshots from the saved run.

Virtual environments, PaddleOCR download caches, and unrelated local work products are excluded.
